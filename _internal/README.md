## 언제 보는가

- 본문 각주의 근거를 원자료까지 역추적할 때
- 다음 회차를 이어서 집필할 때 — 두 파일 모두 `> 서술 규칙:` 블록으로 집필 시 주의사항을 담고 있습니다
- **확인 실패 항목**을 확인할 때. v4 부록 11절이 "찾으려 했으나 근거를 확보하지 못한 것"의 전체 목록입니다

## 주의

두 파일은 집필자를 향한 **지시문 형태**로 쓰여 있습니다(`~하십시오`). 독자용 서술이 아니므로 그대로 인용하지 마십시오.

- v3 정정 완료: MESH 커패시터 세대 표기, Lam Cryo 3.0 수치 혼합
