도해 #33(웨이퍼 맵)의 형상 참고로 쓴 사진 `웨이퍼-참고.jpg`는 **출처가 확인되지 않아 `.gitignore`로 제외**했습니다. 로컬에만 있고 저장소에는 올라가지 않습니다.

해당 도해는 이 사진을 트레이스하지 않고 독자적으로 작성했으므로, 파일이 없어도 저장소는 완결됩니다. 재생성이 필요하면 [assets/IMAGE-MANIFEST.md](../assets/IMAGE-MANIFEST.md) #33 사양만으로 충분합니다 — 사양의 「제외」 항목이 참고 사진의 회절색·사선 원근·광택을 재현하지 말 것을 명시하고 있습니다.
