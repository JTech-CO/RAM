## 0. 이 문서를 읽는 사람이 먼저 알아야 할 것

이번 조사에서 **가장 중요한 결과는 "확인되지 않은 것들"**입니다. 특히:

1. **번인이 줄거나 사라지는 추세** — 확인 실패. 오히려 반대 방향(HBM에서 웨이퍼 레벨 번인 확대) 증거만 나왔습니다. 4절·6절 참조.
2. **메모리 테스트 비용 비중** — 업계 전반 수치(2–3%)는 나왔으나 **원문 직접 확인 실패**(403), 그리고 **DRAM/HBM 특정 수치는 없음**.
3. **번인의 구체적 조건(온도·전압·시간)** — 제조사 공식 수치 확인 실패. 삼성·SK하이닉스 공식 글 모두 "고온·고전압"이라고만 씁니다.
4. **웨이퍼 레벨 병렬도(x512 등)** — 확보한 Advantest 수치는 전부 **패키지 파이널 테스트 기준**입니다. 웨이퍼 레벨 동시 측정 다이 수는 확인 실패. 이 둘을 섞어 쓰면 오류입니다.

## 2. 구조·메커니즘 서술 (집필 참고용)

### 2-1. "만든 뒤 어떻게 걸러내는가"의 전체 흐름

확인된 자료를 종합하면 메모리의 선별은 **웨이퍼 → 패키지 → 모듈**의 3단계 골격 위에 얹혀 있습니다(SK하이닉스, T1). 한국 메모리 업계에서 이 중 웨이퍼 단계를 통칭하는 이름이 **EDS(Electrical Die Sorting)**이며, 삼성은 이를 8대 공정의 하나로 배치합니다(T1).

EDS 내부의 순서는 삼성 공식 자료 기준으로 대략 이렇습니다.

1. **ET Test & WBI** — 먼저 *소자 수준*을 봅니다. 트랜지스터·저항·커패시터·다이오드 같은 개별 소자의 DC 전압·전류 파라미터가 규격 안에 있는지 확인합니다(T1, 직접 인용). 회로가 "동작하는가"를 묻기 전에 "소자가 제대로 만들어졌는가"를 먼저 묻는 셈입니다. 그다음 **웨이퍼 번인(WBI)**으로 열과 AC/DC 전압을 걸어 잠재 불량을 끌어냅니다.
2. **Hot/Cold Test** — 고온과 저온 양쪽 극단에서 기능이 유지되는지 봅니다. 메모리의 실패는 온도 의존성이 강하기 때문에, 상온에서만 보면 놓치는 셀이 생깁니다.
3. **Repair / Final Test** — 여기가 메모리 특유의 지점입니다. 불량 칩이 곧바로 폐기되지 않고, **리페어 가능 판정을 받으면 여분 행·열로 치환해 양품으로 되살립니다.** 그리고 리페어 뒤에는 반드시 **Final Test로 재검증**합니다(T1). 로직 칩에는 없는 단계이며, 메모리가 규칙적 배열 구조라서 가능한 일입니다.
4. **Inking** — 되살릴 수 없는 칩에 잉크를 찍어 표시하고, 이후 공정에서 손대지 않습니다(T1).

> 참고: 삼성 자료 중에는 이 흐름을 5단계(ET & WBI → Pre-Laser → Laser Repair & Post Laser → Tape Laminate & Back Grinding → Inking)로 쪼갠 버전도 있습니다. **레이저 리페어**라는 물리적 수단과 **백그라인딩**(웨이퍼 뒷면 연삭)까지 EDS 범위에 넣은 서술입니다. 3절 참조.

### 2-2. 각 단계가 걸러내는 것 (자료가 뒷받침하는 범위에서만)

- **웨이퍼 테스트(EDS/프로브)**: 패키징하기 전에 개별 다이의 동작 여부를 판정합니다(T1). 여기서 걸러내는 이유는 명확합니다 — 불량 다이를 패키징하면 패키지 재료·공정·시간이 통째로 버려집니다. 삼성 자료의 표현으로는 "조립·품질 비용 절감"입니다.
- **번인**: 기능이 아니라 **수명의 앞부분**을 겨냥합니다. 욕조곡선의 초기 불량 구간을 고온·고전압으로 **가속 소진**시켜, 나중에 고객 손에서 죽을 칩을 공장 안에서 죽이는 조작입니다(SK하이닉스, T1).
- **패키지 테스트(파이널)**: 패키징 과정에서 새로 생긴 결함(본딩, 몰딩, 범프)과 실제 패키지 상태의 전기적 특성을 봅니다. SK하이닉스는 "패키지 단위이므로 장비에 주는 부담이 적다"고 씁니다(T1). 즉 프로브 접촉이라는 물리적 제약이 사라져 조건이 편해집니다.
- **모듈 테스트**: SK하이닉스가 3단계의 마지막으로 명시합니다(T1). 다만 **모듈 테스트가 구체적으로 무엇을 걸러내는지에 대한 확인된 설명은 이번 조사에서 얻지 못했습니다.** (4절)

### 2-3. KGD — 왜 적층에서 갑자기 사활이 걸리는가

단품 DRAM이라면 불량 다이 하나는 다이 하나의 손실입니다. 그런데 **적층하면 손실이 곱해집니다.** FormFactor의 서술(T1)이 이 점을 가장 직설적으로 말합니다: 스택 안의 다이 하나만 불량이어도 패키지 전체를 폐기해야 하고, HBM은 베이스 로직 다이 1개 위에 DRAM 다이 8–16개를 쌓으므로 **베이스 다이가 불량이면 16개 다이가 함께 버려집니다.**

그래서 "패키징 전에 다이 품질을 보증한다"는 요구가 생깁니다. **KGD는 그 보증을 받은 베어 다이**를 가리킵니다 — 포장은 안 됐지만 데이터시트 수준의 품질·신뢰성·기능 사양을 충족한다고 공급자가 보증하는 다이입니다(T3, 단일 출처).

여기에 **테스트 접근성 문제**가 겹칩니다. 적층이 끝난 뒤에는 스택 내부의 다이에 프로브를 물리적으로 댈 수 없습니다. 표면에 노출된 것은 최상단 또는 최하단뿐입니다. 이 문제를 푸는 방식이 두 갈래로 확인됩니다.

- **왼쪽으로 옮기기(shift left)**: 적층 전에, 웨이퍼 상태에서 최대한 다 걸러낸다. 로직 다이 웨이퍼 테스트 단계에서 IEEE 1500 회로·direct access bus·MBIST·내부 로직·TSV 연결성·PHY까지 확인한다는 서술이 있습니다(T3, 간접). 이 요구가 **웨이퍼 레벨 번인을 견인**한다고도 말합니다.
- **DFT 구조로 사후 접근로 만들기**: **IEEE Std 1838-2019**가 이를 표준화했습니다(T0, 2019 비준). 다이마다 **IEEE 1500 기반 die wrapper**를 넣어 두면, 적층 후에도 각 다이와 다이 사이 3D 인터커넥트를 개별적으로 테스트할 수 있고, 스택의 모든 다이가 외부 테스터와 연결됩니다. DWR은 IEEE 1500의 WBR과 요구사항이 매우 유사합니다(T2).

즉 **"적층 후에는 프로브를 못 댄다"는 물리적 사실을 DFT로 우회하고(1838/1500), 그럼에도 남는 위험은 적층 전에 최대한 없앤다(KGD/시프트 레프트)**는 이중 전략입니다.

### 2-4. 프로빙의 물리적 난도

HBM 프로빙은 **55 µm 피치의 마이크로범프 약 4,000개**에 동시에 안정적으로 접촉해야 하는 문제로 서술됩니다(T2, SWTest 발표, 세대 미특정). 난점은 기계·전력공급·신호무결성·처리량의 다차원 문제이고, 특히 **고온에서의 접촉 안정성**과 마이크로범프가 눌려 변형되는 **coining** 거동, 열에 의한 위치 이동이 지목됩니다. 프로브 흔적이 남으면 이후 본딩에 영향을 주기 때문에 "테스트했더니 못 쌓게 되는" 역설이 성립할 수 있다는 점이 이 분야의 본질적 긴장입니다. (단, 이 마지막 인과는 **본 조사에서 직접 확인된 문장이 아니라 해석**입니다 — 6절.)

### 2-5. 병렬 테스트

메모리 테스트의 경제성은 **동시에 몇 개를 보느냐**에 달려 있습니다. 확인된 수치:

- Advantest **T5833**: 파이널 패키지 테스트 **512 디바이스 동시** (T1, 간접)
- Advantest **T5835**: 파이널 패키지 테스트 **768 디바이스 동시**, 5.4 Gbps (T1, 직접 확인)
- 업계 일반: 메모리는 **1,000개 이상 동시 측정**도 가능 (ITRS 2015 기준, 간접)

**주의: 위 수치는 모두 파이널(패키지) 테스트 기준입니다.** 웨이퍼 레벨에서 프로브 카드가 한 번에 접촉하는 다이 수(터치다운당 사이트 수)는 이번 조사에서 확인하지 못했습니다.

### 2-6. 테스트 비용

두 갈래의 수치가 있고, **분모가 다릅니다.**

- ITRS 2015: 효율 개선의 결과 테스트 비용은 **IC 매출의 2–3% 미만** (간접 인용)
- Semiconductor Engineering: 수십 년간 **총 제조원가의 2%**라는 관행적 수치가 쓰였으나, 최근 신뢰성 요구 상승으로 **비중이 오르는 중** (간접 인용)

**DRAM/HBM에 특정된 테스트 비용 비중은 확인 실패입니다.** 본문에서 "메모리 테스트가 원가의 X%"라고 쓰면 안 됩니다.

## 4. 확인 실패 항목

**아래 항목은 값을 만들어 넣지 마십시오.**

1. **번인의 구체적 조건** — 온도, 전압(정격 대비 몇 %), 지속 시간(시간 단위). 삼성·SK하이닉스 공식 글 모두 "고온·고전압"이라고만 서술. **DRAM 번인이 몇 시간인지 확인 실패.**
2. **번인이 줄거나 사라지는 추세** — 확인 실패. 반대 방향 증거만 확보(3절).
3. **DRAM/HBM 테스트 비용의 총 제조원가 대비 비중** — 확인 실패. 업계 전반 수치(2–3%)조차 원문 PDF 접근 실패(403)로 **간접 인용 상태**.
4. **웨이퍼 레벨 병렬도(프로브 터치다운당 동시 측정 다이 수)** — 확인 실패. 확보한 512/768은 전부 파이널 테스트 기준. 과제에서 언급된 "x512"는 **웨이퍼 레벨이 아니라 패키지 테스트 수치와 일치**함에 주의.
5. **테스트 시간(TAT)** — 다이당/웨이퍼당 테스트 소요 시간 수치 확인 실패.
6. **IEEE 1500 원문(IEEE Std 1500-2005)** — 표준 원문 직접 확인 실패. 1500에 대한 서술은 전부 1838 해설 문헌을 경유한 간접 정보.
7. **삼성·SK하이닉스의 KGD 공식 정의** — 확인 실패. 확보한 정의는 장비사·문헌 쪽 정의(T3, 단일 출처).
8. **Teradyne 메모리 테스터(Magnum 계열 등) 제품 사양** — 검색 예산 소진으로 **조사 미실시**. 확인 실패가 아니라 미조사.
9. **모듈 테스트가 구체적으로 무엇을 걸러내는가** — SK하이닉스가 3단계 중 하나로 명시했을 뿐, 내용 확인 실패.
10. **Inking이 현대 라인에서 전자 웨이퍼 맵으로 대체되었는지** — 확인 실패. 삼성 공식 글은 여전히 잉킹을 기술하고 있으나, 그것이 현행인지 설명용 서술인지 불명.
11. **WLBI가 실제 DRAM 양산에서 어느 정도 비중으로 쓰이는지** — 확인 실패(장비사·시장조사 자료만 존재하며 이들은 T4).
12. **HBM 프로빙 수치(4,000 범프 / 55 µm 피치)의 세대** — HBM 몇 세대 기준인지 확인 실패. SWTest 발표 시기상 HBM2 세대일 가능성이 있음.

## 5. 기존 소스 팩(v3/v4)과의 충돌

**없음.**

- `RAM-source-pack.md` 515행에 8대 공정 나열(`… ⑦ EDS → ⑧ 패키징`)이 있을 뿐, EDS 내용 서술은 없습니다. 본 문서는 그 공백을 채웁니다.
- `RAM-source-pack-v4-addendum.md` 1085행의 "번인 기간" 언급은 **SSD 필드 데이터의 초기 고장 구간(bathtub curve 좌측)**에 관한 것으로, 본 문서의 제조 공정상 번인(burn-in 공정)과 **용어만 같고 대상이 다릅니다.** 충돌 아님. 다만 집필 시 두 용법이 한 문서에 섞이면 독자가 혼동하므로 6절 참조.

## 6. 집필 시 주의 (서술 규칙 제안)

1. **"번인은 줄어드는 추세" 서술 금지.** 이번 조사에서 그 근거를 찾지 못했고, 확보된 증거는 전부 반대 방향(HBM용 WLBI 확대, HBM4 번인 테스터 도입)입니다. 굳이 추세를 언급하려면 "적어도 HBM에서는 번인이 오히려 웨이퍼 단계로 앞당겨지며 강화되는 방향의 보도가 있다"고 쓰고 T3 출처를 밝히십시오.

2. **병렬도 수치의 단계를 반드시 붙이십시오.** "Advantest T5835는 768개 동시 측정"이 아니라 "**패키지 파이널 테스트에서** 768개 동시 측정(2021년 발표 제품)"이라고 써야 합니다. 웨이퍼 레벨 수치로 오독되면 사실 오류입니다.

3. **테스트 비용 수치는 쓰지 않는 편이 안전합니다.** 쓴다면 (a) 분모가 매출인지 제조원가인지 명시, (b) 2015년 ITRS 기준임을 명시, (c) 메모리 특정 수치가 아님을 명시, (d) 원문 직접 확인 실패 상태임을 감안해 "업계 관행적으로 인용되는 수치" 정도의 톤으로.

4. **온도 85–90 ℃ / -5–-40 ℃는 단일 출처이며 맥락이 애매합니다.** SK하이닉스 컬럼에서 나온 "메모리 반도체의 고온 시험 / 저온 시험" 범위인데, 이것이 번인 조건인지 Hot/Cold 기능 시험 조건인지 원문 맥락이 확실하지 않습니다. 쓴다면 "**메모리 시험 온도 범위**"로 중립적으로 쓰고 번인 조건이라고 단정하지 마십시오.

5. **번인(burn-in, 공정)과 번인 기간(bathtub curve 좌측 구간)을 구분하십시오.** v4 부록 1085행이 후자의 뜻으로 쓰고 있어, 한 원고에 섞이면 독자가 "SSD도 공장에서 번인을 한다"로 오해합니다. 전자는 **제조사가 하는 조작**, 후자는 **현장에서 관측되는 구간**입니다.

6. **EDS 단계 수는 4/5 두 서술이 모두 삼성 공식입니다.** 하나를 정답처럼 제시하지 마십시오. 기능 흐름으로 풀어 쓰는 편이 안전합니다.

7. **"적층 후에는 프로브를 못 댄다"는 서술은 정확하되, 그 다음 문장이 중요합니다.** 그래서 산업이 한 일은 (a) IEEE 1838/1500 die wrapper로 **전기적 접근로**를 미리 설계에 넣은 것, (b) 적층 전에 최대한 걸러내는 것(KGD·시프트 레프트)입니다. "못 댄다 → 그래서 못 한다"가 아니라 "못 댄다 → 그래서 설계 단계에서 길을 뚫어 둔다"로 이어져야 합니다.

8. **KGD 정의는 장비사·문헌 쪽 정의만 확보했습니다.** "메모리 제조사가 공식적으로 이렇게 정의한다"고 쓰지 마십시오. "베어 다이지만 패키지 부품과 동등한 품질 보증을 받은 다이" 정도의 기능적 설명이 안전합니다.

9. **리페어 후 재검증(Final Test)을 빠뜨리지 마십시오.** 메모리 선별의 특징은 "불량을 버린다"가 아니라 "**되살리고 다시 검사한다**"입니다. 이 대목이 로직 칩과 갈라지는 지점이고, 기존 소스 팩의 PPR(§4.23) 서술과도 자연스럽게 이어집니다 — 다만 **EDS 단계의 레이저 리페어(제조 시점, 퓨즈/레이저)와 필드에서의 PPR(사용 시점, DRAM 명령)은 전혀 다른 메커니즘**이므로 반드시 구분해 서술하십시오.

10. **"수천 개 테스트 패턴", "1,000개 이상 동시 측정" 같은 표현은 정성 표현으로 취급하십시오.** 정확한 수치가 아니라 규모감의 서술입니다.

11. **간접 인용(검색 요약 경유) 항목이 많습니다.** 1절 표의 "검색 요약 경유", "원문 403" 표시가 붙은 항목은 원문 문장을 직접 보지 못한 상태입니다. 본문에 직접 인용부호를 붙여 옮기지 마십시오.
