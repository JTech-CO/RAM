# IMAGE MANIFEST — 이미지 매니페스트

> **최종 검증: 2026-07-29**
> 이미지는 추후 생성하며, 집필 단계에서는 **플레이스홀더 텍스트만** 본문에 존재합니다.
> 이 파일은 플레이스홀더의 원문·정규화 문자열·배치 위치·생성 시 유의사항을 관리하는 단일 창구입니다.

현재 상태: **28건 전부 미생성.** 생성된 이미지는 이 디렉터리(`assets/`)에 둡니다.

**추가 제안 19건**이 [RAM-source-pack-v4-addendum.md](../_internal/RAM-source-pack-v4-addendum.md) 9절에 등록되어 있습니다. 아직 본문에 배치하지 않았으며, 다음 집필 회차에서 선별해 반영합니다. 이 파일의 표는 **본문에 실제로 배치된 것만** 관리합니다.

---

## 1. 표기 규약

```
[<이미지 종류> - <담아야 할 핵심 요소>, <표현 형식>]
```

- 마크다운 이미지 문법(`![]()`)을 쓰지 않고 **대괄호 텍스트를 그대로** 본문에 남깁니다. 미생성 상태가 렌더링에서 즉시 눈에 띄어야 하기 때문입니다.
- 코드 블록으로 감싸지 않습니다. 본문에 단독 줄로 둡니다.
- 종류는 **6종으로 통일**합니다: `셀 구조도` / `단면도` / `구조도` / `비교도` / `흐름도` / `개념도`
- 플레이스홀더 바로 아래 한 줄 띄고 이탤릭 캡션을 답니다. 번호는 `그림 <문서번호>-<일련번호>`.

**예시**

```markdown
[단면도 - DRAM 셀 수직 구조, 실린더형 커패시터 + 매몰 워드라인 + 비트라인 컨택]

*그림 2-2. 1T1C DRAM 셀의 수직 단면 구조*
```

## 2. 종류 정규화 매핑

소스 자료의 매니페스트 원문에는 6종 규약에 없는 종류 이름 5개가 섞여 있었습니다. 규약이 "6종으로 통일"을 명시하므로 아래와 같이 정규화했고, **원문 문자열은 3절 표의 `원문 종류` 열에 보존**했습니다.

| 원문 종류 | 정규화 후 | 해당 항목 | 판단 근거 |
|---|---|---|---|
| `그래프` | `비교도` | #7 | 세대별 값을 나열·대조하는 형식. 같은 성격의 #3이 이미 `비교도`로 지정되어 있어 일관성을 맞춤 |
| `아키텍처도` | `구조도` | #11 | 물리적 구성 요소의 배치를 그리는 그림. #8·#10과 동일 성격 |
| `경로도` | `흐름도` | #15 | 데이터가 지나가는 경로의 순서를 표현 |
| `구성도` | `구조도` | #22 | 프로토콜 스택의 구성 배치 |
| `토폴로지도` | `개념도` | #23 | 물리 배치가 아니라 연결 방식의 진화를 개념적으로 표현 |

> 정규화는 종류 이름에만 적용했습니다. 각 플레이스홀더의 **내용 서술부는 원문 그대로**입니다.

## 4. 생성 시 공통 원칙

- **제조사 공식 이미지 전재 불가.** 전부 자체 생성합니다. 참고는 하되 재현하지 마십시오.
- 텍스트 라벨은 한글 + 영문 약어 병기. 예: `매몰 워드라인 (Buried WL)`, `관통 실리콘 비아 (TSV)`.
- 계층 간 비교 이미지(#8·#10, #4·#13 등)는 **동일 스케일·동일 스타일**로 생성해야 비교가 성립합니다.
- 수치가 들어가는 이미지(#3, #7, #9, #21)는 본문 수치와 반드시 일치시킬 것. **본문 수치를 갱신하면 이미지도 함께 갱신**합니다.
- 다크 모드에서도 읽히도록 배경 의존적인 표현(흰 배경 전제의 얇은 회색선 등)을 피하십시오.
- 벡터 형식(SVG)을 기본으로 합니다. 래스터가 불가피하면 최소 2배 해상도로.

이미지를 생성한 뒤 아래 순서로 반영합니다.

1. 생성 파일을 `assets/`에 둡니다. 파일명 규칙: `<문서번호>-<일련번호>-<영문-슬러그>.svg` (예: `02-02-dram-cell-cross-section.svg`).
2. 본문의 플레이스홀더 줄을 `![캡션](assets/파일명.svg)` 로 치환합니다. 그 아래 이탤릭 캡션 줄은 **그대로 둡니다**.
3. 이 파일 3절 표의 `파일명` 열과 `상태` 열을 갱신합니다. **플레이스홀더 원문 문자열은 지우지 마십시오** — 원본 지시가 보존되어야 재생성이 가능합니다.
4. 수치가 들어간 이미지라면 [SOURCES.md](../SOURCES.md) 갱신 이력에도 한 줄 남깁니다.
